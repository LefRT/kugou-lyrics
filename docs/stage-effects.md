# 舞台特效词典（播放界面）

> 用途：给舞台里每一个看得见的效果一个**固定名字**。以后沟通直接说名字（"彗星再粗一点""
> 色散关掉""取景框概率降到 15%"），不用截图比划。
>
> 规则：名字一旦定下就不要改；代码里的函数名/选择器也尽量保持不变。新增效果按同样格式登记。
>
> 变更：2026-11-04 移除 回声鬼影 / 巨型残字 / 空心描边（用户不要残影类）；彗星导引全面加大；
> 新增 环境流星 / 反白闪帧。
> 变更：2026-11-05 移除 四角题字（歌名经常对不上）；新增 歌词退场（旧句去边缘淡出、新句居中进场）；
> 镜头随机偏移与横条扫镜收紧（歌词主体始终居中）；装饰新增 8 种几何（同心方环/星芒/套准标记/
> 三角叠/条码带/半调点带/弧线组/菱形链），取景框变体 4→6；歌曲队列切歌加淡入淡出。
> 变更：2026-11-05 移除 反白闪帧（用户把整屏反相看成"曝光闪白"，不要）。
> 变更：2026-11-05 重写转场：删除 快速模糊/单色故障/淡出转场 三种转场与对应滤镜
> （条带撕裂+模糊被看成"鬼影"），改为唯一 **净空淡变**；歌词退场提速（0.5s、不放大）。

## 1. 背景与画框（DOM 层，不在 WebGL 里）

### 网点底片 · Halftone Plate
- 代码：`background.ts:28 bakeHalftone()`
- 做法：bg.jpg 按 cover 裁切 → 降采样 → 15° 网屏重新画点，点径 = √亮度。整页只烘焙一次。
- 参数：`cell=5.2`（点阵格子 px）、`contrast=0.42`、`bright=0.05`、输出宽 1280~1920。
- 观感：所有截图里那层灰色密密麻麻的圆点。

### 呼吸漂移 · Slow Drift
- 代码：`background.ts:108 mountBackground()`（WAAPI keyframes，24 采样）
- 参数：`DRIFT_LOOP_SECONDS=240`、平移 ±3.4%、呼吸 ±3.5%、预放大 overscan ≈1.113。
- 注意：底图必须预放大，否则平移时会露边。

### 压暗幕 · Dim Veil
- 代码：`.bg-dim`，`style.css:1074`，`opacity: 0.52`。
- 作用：让白字始终压得住底图；调低字会更"浮"，调高底图更黑。

### ~~四角题字 · Corner Title~~（已移除 2026-11-05）
- 原实现：当前段落歌名前 4 字钉在四角（background.ts setTitle + .bg-title-char）。
- 移除原因：歌名取自"当前段落第一行"，间奏/跨段时常显示错歌名，用户要求删除。
- 录制器的 drawTitleChars 与 style.css 的 .bg-title 系列一并删除；`BackgroundHandle` 只剩 setFlash。

### 画框角标 · Frame Overlay
- 代码：`runtime.ts:31 buildFrameOverlay()`
- 做法：四角 26px 的 L 形线（alpha .28）+ 上下边缘各 7 根刻度（alpha .18），常驻不参与动画。

### 暗角 · Vignette
- 代码：`filters.ts:80`，`runtime.ts:161 createVignetteFilter(0.85)`
- 参数：`smoothstep(0.52, 1.08) * 0.85 * 0.6`，最大压暗约 51%。

## 2. 镜头与节奏（Pixi）

### 镜头语法 · Shot Grammar
- 代码：`motion.ts:67 resolveShotMotionFrame()`；分镜类型在 `program.ts:7 ShotKind`
- **版面引擎 2026-11-05 一比一移植 Folia**（layouts.ts）：自研模板全部废弃，改为逐行移植
  Folia sonnet 的 `sonnetTypographyLayout.ts` + `sonnetShotFlowLayouts.ts` + `sonnetPosterBlocksLayout.ts`——
  精确测量盒 + 时间线扫描顺序流式排布 + 整体等比缩放重试（placeWithGlobalFit 档位
  1→0.52），构图家族：安静竖列(4变体)/横排缎带(3)/杂志竖排(5)/碎片极轨(3)/动态十字/海报区流
  （zone float 换行 + 紧急适配）。仅两处差异：测量用 canvas 2D（渲染同尺）、不移植 Folia 的
  decoration 块（残影类已禁）。镜头路径/相机应用与 Folia 逐帧一致，但 zoom/随机偏移保留
  本项目收紧值（zoom ≤1.06，Folia 原版 1.22~1.48）——扫镜时构图边缘少量出画是 Folia
  本来的观感。

### 手持呼吸 · Camera Breath
- 代码：`motion.ts:109`，权重 `motion.ts:121`
- 做法：多个不可通约正弦叠加；最后一个字落位后 1.2s 渐入。
- 幅度：位移 0.6% 屏、缩放 0.2%、旋转 0.0015rad。

### 追字焦点 · Focus Tracking
- 代码：`motion.ts:160/178`，`runtime.ts:362-393`
- 做法：按高斯权重（σ=0.35s）混合各词的"当前唱到字"位置，再做 ±0.12s 五点平滑；
  位移超过 96px 的构图跳变不被平均（保边）。追踪系数 0.5，即镜头只跟一半。

### 节拍脉冲 · Beat Pulse
- 代码：`stage.ts:217 updateBeat()`，`runtime.ts:396`
- 触发：频谱前 10 个低频 bin 均值 >0.52，且比滑动峰值高 12%，两次间隔 ≥180ms。
- 幅度：推近最多 2.8%，旋转 ±0.004rad 并以 2Hz 交替方向；包络每帧 ×0.9 衰减。

### 空拍余漂 · Gap Drift
- 代码：`runtime.ts:342`
- 做法：分镜结束后按 `1-exp(-t*0.4)` 把镜头继续推向镜尾方向，×2 倍，避免"停尸"。
- 2026-11 起：空拍期间旧歌词不再滞留——唱完 0.8s 内开始整体向外缘漂移淡出（见 歌词退场）。

### 歌词退场 · Line Exit（2026-11 新增）
- 代码：`runtime.ts` `exitStartTime/exitEndTime`（buildShotView）+ `resolveExitAmount()` + updateGlyph 退场分支
- 时机：本句唱完最多滞留 0.8s；下一分镜开始前 0.55s 提前起退（与下一句的入场重叠 0.55s）；
  整段退场历时 0.9s。段落最后一个分镜唱完 0.8s 后退场（尾奏/间奏不再留旧词）。
- 做法：每个字从版面中心沿自身方向推向外缘（位移 = exit² × (0.24 屏宽+140px)），
  同时放大 12%、旋转 0.08rad、淡出；正中心的字向上缘退。
- 效果：新句在中心进场时，旧句正漂向屏幕边缘——用户指定的"新句居中、旧句去边缘退场"。
- 切歌淡出：`StageHandle.clearText()`（stage.ts 在 ended/错误跳歌时调用）把整屏歌词 alpha
  在约 0.35s 内压到 0，`setProgram` 复位——歌与歌之间的前奏期画面干净。

### 贴花视差 · Decor Parallax
- 代码：`runtime.ts:409`
- 做法：装饰粒子层跟 0.4× 相机位移、0.3× 相机缩放，并自转 0.05rad/s。

### 强度档 · Intensity Dial（总开关，不是单个效果）
- 代码：`motion.ts:38-42`，`ANIMATION_INTENSITY = 'chaotic'`（1.35）
- calm 0.65 / normal 1 / chaotic 1.35，统一缩放相机运动与入场位移。改一个词就能整体收/放。

## 3. 文字层（逐字）

### 打击入场 · Impact Entrance
- 代码：`runtime.ts:451-461`，`textView.ts:80`
- 做法：ExpoOut，时长 `clamp(0.42×分镜时长, 0.65s, 1.8s)`；相邻字左右/上下交替错开
  （`stagger=±1`，横排错开 0.24em，竖排 0.28em）+ 微小旋转。
- 特例：`type-impact` 的主角词从 0.52 倍放大到 1。

### 角色字阶 · Role Ladder
- 代码：`program.ts:175-179`，`layouts.ts:649-675`
- 字重：主角/半主角 900，配角 700（装饰字重 300 已随巨型残字移除）。
- 字号：主角 3.0~5.5×基础字号（按分镜），半主角 ≈ 主角 0.72 倍，配角 1.15~1.6×。
- 主角/半主角判定：词长、时长、是否包含串烧关键词，`program.ts:117-173`。

### 红青色散 · Chromatic Split
- 代码：`textView.ts:202-224`，每帧收敛 `runtime.ts:475-486`
- 做法：每个非装饰字都带两个 screen 混合副本：青 `#00ffff`、红 `#ff0044`；
  主角偏移 `0.025em`、配角 `0.010em`，随字落位收拢 80%（只留 20%）。
- 认图：图2"慕"左右两边的青/红彩边；图4 白字边缘的彩色描边。

### 辉光 · Glow
- 代码：`textView.ts:156`
- 做法：TextStyle dropShadow，模糊半径 `max(12, 0.18em)`、alpha .8、距离 0。
  主角用字色发光，配角用强调色发光。

### ~~回声鬼影 · Echo Ghost~~（已移除 2026-11-04）
- 原实现：半主角词背后两层空心描边残影（textView.ts / runtime.ts updateGlyph）。
- 移除原因：用户不要残影类效果。相关代码（GlyphGhostView、ghostStyle、ghost 动画块）已删除。

### ~~巨型残字 · Giant Echo~~（已移除 2026-11-04）
- 原实现：主角词复制 2.8~5.5 倍空心复刻压在背景里（layouts.ts decoration 块）。
- 移除原因：同上。`'decoration'` 角色与 300 字重也一并删除，角色只剩 hero / semi-hero / support。

### ~~空心描边 · Outline Type~~（已移除 2026-11-04）
- 原实现：fill 透明 + stroke 的描边字，只服务于上面两个残影，随它们一起删除。

### ~~反白闪帧 · Impact Flash~~（已移除 2026-11-05）
- 原实现：主角词首字落位瞬间整屏反相（CSS invert 同步 Pixi 画布 + DOM 背景，录制合成里
  ctx.filter 同步），窗口 0.08s、每分镜最多 2 次。
- 移除原因：暗色网点反相后是整片亮白，观感像"曝光闪白"，用户不要。相关代码
  （flashHits、onFlash 钩子、background.setFlash、recorder flashAmount）已全部删除。

## 4. 导引与贴花

### 彗星导引 · Comet Cue（图2 红框、图3 左下）
- 代码：`guides.ts:16/91-118`
- 时机：词出现前 `clamp(0.18+0.1×时长, 0.2s, 0.38s)` 开始，到词出现后 0.65s 消失。
- 做法：三次贝塞尔（入场方向 → 词中心）画 28 段，越靠头越粗越亮；头部光环主角 22px /
  配角 14px，纯白点主角 7px / 配角 4.5px。轨迹描画进度 0.35、0.4 后淡出。
- 2026-11 加大：拖尾宽主角 `4+9×intensity`、配角 `2.5+5×intensity`（原 2.5/5 与 1.5/3），
  入场距离 1.8em → 2.6em，配角描边 alpha 0.55 → 0.62。
- 认图：截图里那道"末端有个亮点"的短亮线。

### 环境流星 · Ambient Comet（2026-11 新增）
- 代码：`guides.ts buildAmbientComets()`，挂载 `runtime.ts buildShotView()`，更新 `runtime.ts updateShot()`
- 触发：每个分镜种子随机 1~3 条，在分镜窗口内随机时刻划过（全部确定性 RNG，seek 安全）。
- 做法：屏幕外左/右入场，横向划过 30%~60% 屏宽带纵向弧线，时长 0.9~1.6s；
  拖尾宽 3~6px（24 段锥形收窄）、头部光环 18~26px、白心 5~7.5px，
  峰值透明度 0.35~0.5，40% 概率用强调色（红）其余用次色。
- 层级：0.4× 视差垫在文字后面（与贴花视差同层逻辑），只压背景不抢字。
- 认图：空拍时背景里慢慢划过的长亮线（比彗星导引更长更淡）。

### 迸发粒子 · Burst Sparks

  淡出，后 70% 时间完成。位置是 `Math.random()`，每次播放不同（唯一非确定性的效果）。

### 取景框装饰 · Frame Decor（图1 红框）

  3. 双层折角框 + 四边菱形（brackets）
  4. 角上三角 + 边线为虚线（triangles + dashed）
  5. 双线框 + 角部实心方块（double rule + corner squares）
  6. 虚线框 + 四边中点菱形（dashed + midpoint diamonds）

## 5. 转场（2026-11-05 整块重写）

旧系统有三种转场：快速模糊（fast-blur）、**单色故障**（mono-glitch，横向条带撕裂）、
淡出转场（camera-pull）。用户反馈条带撕裂/模糊让字看起来像"鬼影/重影"，
整块删除重写——现在只有一种转场：

| 名字 | 实做 | 时长 |
